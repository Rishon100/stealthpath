# StealthPath

Detection-aware attack path planning in Active Directory.

## Research question

StealthPath investigates how different attack-path planners behave
when evaluated on Active Directory graphs while considering detection
exposure.

## Planners

1. Shortest-path
2. Risk-weighted
3. Reinforcement learning

## Current stage

Initial graph representation and planner validation.

## Dataset

The project will first use toy/synthetic graphs for validation.
A real authorized SharpHound collection will be used only after the
pipeline has been verified.
